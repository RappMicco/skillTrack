# SkillTrack

SkillTrack is a web-based Training and Skill Management System designed to help organizations monitor employee development, track training progress, manage skill matrices, and visualize career growth.

## 🚀 Features

### 📊 Dashboard
- Overview of training statistics
- Total Upcoming Trainings
- Ongoing Trainings
- Completed Trainings
- Pending Trainings
- Employee Skill Overview

### 🎯 Training Management
- Create and manage training plans
- Assign training to employees
- Set start and end dates
- Track training status
- Monitor completion progress

### 🧠 Skill Matrix
- Track employee skills and proficiency levels
- View skill gaps
- Manage technical and non-technical skills
- Support career development planning

### 🛣️ Skill Path
- Define learning and career paths
- Visualize employee growth journey
- Track completed and upcoming learning milestones

### 🏫 Training Providers
Manage training sources such as:
- Udemy
- Internal Training
- External Seminars
- Workshops
- Certification Programs

### 📈 Reports & Analytics
- Training completion reports
- Skill development reports
- Employee progress tracking
- Training participation analysis

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Other Tools
- JWT Authentication
- REST API
- Git & GitHub

## 📋 Training Status

| Status | Description |
|----------|-------------|
| Upcoming | Training has been scheduled but not started |
| Ongoing | Training is currently in progress |
| Completed | Training has been successfully finished |
| Pending | Training is awaiting approval or schedule |

## 🎯 Purpose

SkillTrack aims to provide a centralized platform for managing employee training and skill development. It helps organizations:

- Monitor employee growth
- Identify skill gaps
- Improve workforce competency
- Support career development
- Increase training visibility
- Simplify training management processes
